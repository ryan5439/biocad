# SPECTRA EQ 2.3.9-expand

## If title bar says `2.3.5` you are running the OLD EXE

Close it. Rebuild from **this** folder, then run:

`SpectraEQ-2.3.9-expand.exe`

## What's fixed in 2.3.9

- Full HUD / status / device names (wrapped — no `…` cutoffs)
- Wider PLAY/CAPTURE dropdown menus (2-line names)
- Microsoft Sound Mapper / Primary Sound removed from PLAY list
- Setup panel for Headphones **and** Speakers-via-VB-Cable
- Footer tip fully expanded

## Build (Windows)

1. Unzip so `Eq.py` + `build_exe.bat` are together  
2. Double-click `build_exe.bat`  
3. Open **`SpectraEQ-2.3.9-expand.exe` only**

## EQ ON — two setups

**A) Headphones** — CAPTURE Speakers, PLAY = Headphones → EQ ON  

**B) Speakers via VB-Cable** — install VB-Cable, Windows default = **CABLE Input**, then EQ ON
