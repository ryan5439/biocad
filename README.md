# BioCAD Studio (stackdrop.it)

Interactive BioCAD demo: load an organism, edit phenotype and intelligence traits, then print DNA. Marketing pages included under `marketing/`.

**Live:** https://stackdrop.it/biocaddemo/  
**Stack:** Static SPA (Vite/Three.js build), HTML/CSS/JS

Deploy the `biocaddemo/` folder as static files at `/biocaddemo/`.
